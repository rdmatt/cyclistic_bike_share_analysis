# Estudo de Caso: Análise de Dados do Google

## 📌 Visão Geral do Projeto
Este projeto faz parte do Certificado Profissional de Análise de Dados do Google. O objetivo principal é realizar uma análise exploratória para identificar padrões de comportamento de usuários e recomendar estratégias de conversão baseadas em dados.

- **Status do Projeto:** Concluído
- **Dashboard Interativo:** https://public.tableau.com/views/TCCGoogleDataAnalyticsAnlisedoComportamentodeUsodeBicicletas-Cyclistic/Painel1?:language=pt-BR&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

---

## 🎯 Problema de Negócio & Objetivos
- **Pergunta Principal:** Como os diferentes perfis de usuários utilizam o produto/serviço?
- **Objetivo:** Identificar tendências de uso para orientar decisões estratégicas de marketing e conversão.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagens:** Python / R
- **Visualização de Dados:** Tableau
- **Processamento de Dados:** Manipulação de Big Data (+6 milhões de registros)
- **Metodologia:** Processo de Análise de Dados do Google (Perguntar, Preparar, Processar, Analisar, Compartilhar e Agir)
