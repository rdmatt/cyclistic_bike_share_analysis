# Estudo de Caso: Análise de Dados do Google

## 📌 Visão Geral do Projeto
Este projeto faz parte do Certificado Profissional de Análise de Dados do Google. O objetivo principal é realizar uma análise exploratória para identificar padrões de comportamento de usuários e recomendar estratégias de conversão baseadas em dados.

- **Status do Projeto:** Concluído

## 🎯 Problema de Negócio & Objetivos
- **Pergunta Principal:** Como os diferentes perfis de usuários utilizam o produto/serviço?
- **Objetivo:** Identificar tendências de uso para orientar decisões estratégicas de marketing e conversão.

## 🔍 Principais Insights e Descobertas
1. **Insight 1:** Duração Média das Viagens: Usuários casuais passam, em média, quase o dobro do tempo por corrida comparados aos membros anuais (foco em passeio/lazer).

2. **Insight 2:** Padrão Semanal:

  Membros Anuais: Mantêm alto volume de uso de segunda a sexta-feira, com picos nos horários de pico (perfil utilitário/deslocamento para o trabalho).

  Usuários Casuais: O volume dispara aos sábados e domingos (perfil recreativo).

3. **Insight 3:** Estacionalidade: O uso por ciclistas casuais cresce acentuadamente nos meses quentes de verão (junho a agosto) e cai drasticamente durante o inverno.

---

## 💡 Recomendações Estratégicas (Agir)
- **Recomendação 1:** Planos Promocionais de Fim de Semana: Criar uma campanha direcionada no aplicativo aos sábados e domingos (onde o fluxo de casuais é maior), oferecendo descontos na conversão para o plano anual ou passes sazonais de fim de semana.

- **Recomendação 2:** Pacote de Verão com Opção de Upgrade: Lançar uma "Assinatura de Verão" que permita aos usuários casuais abaterem o valor pago no passe sazonal caso decidam migrar para a assinatura anual completa antes do outono.

- **Recomendação 3:** Comunicação Focada em Lazer e Saúde: Posicionar o marketing digital destacando que a assinatura anual não serve apenas para o deslocamento diário, mas oferece economia real para quem usa as bicicletas para lazer nos fins de semana e passeios mais longos.
